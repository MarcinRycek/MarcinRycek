
# Cześć, jestem Marcin! 👋

> Pasjonat administracji systemami Linux, cyberbezpieczeństwa sieciowego oraz automatyzacji infrastruktury IT.

Obecnie skonczyłem studia informatyczne i aktywnie rozwijam się w kierunku ról związanych z administracją systemami, wsparciem IT. Szczególną uwagę poświęcam na zarządzanie środowiskami Linux, konfiguracji urządzeń sieciowych (routing, switching, firewalle), automatyzacji infrastruktury oraz wdrażaniu i zabezpieczaniu kontenerów (Docker, Kubernetes).

## 🛠️ Technologie i Narzędzia

**Infrastruktura i Automatyzacja:**
* **Systemy operacyjne:** Linux, Proxmox VE
* **Automatyzacja:** Ansible, Bash
* **Chmura:** Google Cloud Platform (podstawy - VPC, KMS)

**Sieci i Bezpieczeństwo:**
* Cisco (zagadnienia CCNA: VLAN, STP, DHCP Snooping)
* Routing i Firewall: OPNsense
* Analiza i hardening zabezpieczeń

**Konteneryzacja i Orkiestracja:**
* Docker (ze szczególnym naciskiem na Hardening i CIS Benchmarks)
* Kubernetes (minikube, k3s)


**Programowanie i Bazy Danych:**
* **Języki:** Python, Rust (podstawy), Prolog
* **Bazy danych:** PostgreSQL, MySQL
